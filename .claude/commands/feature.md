Create a new feature branch, push to remote, and set up tracking.

# Input

- Branch name (required)

# Process

1. Ensure working directory is clean (stash changes if needed)
2. Switch to main branch and pull latest changes
3. Create new feature branch from main
4. Push new branch to origin with upstream tracking
5. Switch to the new branch
6. Display branch status and setup confirmation

# Output

- Plain text only (no TUI elements, markdown, or formatting)
- Confirmation of branch creation
- Remote tracking setup status
- Current branch and its upstream
- Any stashed changes that need attention
